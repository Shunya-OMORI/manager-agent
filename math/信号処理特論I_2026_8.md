## 干渉除去 (2/15)

✓ 未知ベクトル $\boldsymbol{x}^*$ の特定の成分 $x_n^*$ のみの復元を考えると他の成分は干渉になる

観測モデル：
$$\boldsymbol{y} = \boldsymbol{A}\boldsymbol{x}^* + \boldsymbol{v} = \sum_{n=1}^{N} \boldsymbol{a}_n x_n^* + \boldsymbol{v} \quad \left(\boldsymbol{A} = [\boldsymbol{a}_1 \ \cdots \ \boldsymbol{a}_N]\right)$$

たとえば $x_1^*$ に着目すると

$$\boldsymbol{y} = \underbrace{\boldsymbol{a}_1 x_1^*}_{\text{所望成分}} + \underbrace{\sum_{n=2}^{N} \boldsymbol{a}_n x_n^*}_{\text{干渉成分}} + \underbrace{\boldsymbol{v}}_{\text{雑音成分}}$$

何かしらの手法で得られた仮の推定値を用いて干渉の影響を除去できれば復元精度が改善されるかも？
→ 無線信号検出などで活用

- 逐次干渉除去
- 並列干渉除去

## 逐次干渉除去 (3/15)

✓ 干渉を除去しながら**1つずつ**成分を推定

1. $\boldsymbol{y} = \boldsymbol{a}_1 x_1^* + \sum_{n=2}^{N} \boldsymbol{a}_n x_n^* + \boldsymbol{v}$ から、観測を $\boldsymbol{y}$、観測行列を $\boldsymbol{a}_1$、雑音を $\sum_{n=2}^{N} \boldsymbol{a}_n x_n^* + \boldsymbol{v}$ と思って $x_1^*$ の推定値 $\hat{x}_1$ を計算（例：ZF推定）

2. $\boldsymbol{y} - \boldsymbol{a}_1\hat{x}_1 \approx \boldsymbol{a}_2 x_2^* + \sum_{n=3}^{N} \boldsymbol{a}_n x_n^* + \boldsymbol{v}$ から、観測を $\boldsymbol{y} - \boldsymbol{a}_1\hat{x}_1$、観測行列を $\boldsymbol{a}_2$、雑音を $\sum_{n=3}^{N} \boldsymbol{a}_n x_n^* + \boldsymbol{v}$ と思って $x_2^*$ の推定値 $\hat{x}_2$ を計算

3. $\boldsymbol{y} - \boldsymbol{a}_1\hat{x}_1 - \boldsymbol{a}_2\hat{x}_2 \approx \boldsymbol{a}_3 x_3^* + \sum_{n=4}^{N} \boldsymbol{a}_n x_n^* + \boldsymbol{v}$ から（以下同様に繰り返す）

- $x_1^*, x_2^*, \ldots, x_N^*$ の大きさに差がある場合に有効
- $x_n^*$ が離散値をとる場合は推定値を丸めてからの干渉除去も可能

## 信号復元の確率的モデル化 (5/15)

✓ 未知ベクトル $\boldsymbol{x}^* \in \mathbb{R}^N$ や雑音ベクトル $\boldsymbol{v} \in \mathbb{R}^M$ を確率変数として考える

$$\boldsymbol{y} = \boldsymbol{A}\boldsymbol{x}^* + \boldsymbol{v}, \quad M \times (N \text{ 列の } \boldsymbol{A})$$

- $\boldsymbol{x}^*$：確率変数 $\boldsymbol{X} \in \mathbb{R}^N$ の実現値
- $\boldsymbol{v}$：確率変数 $\boldsymbol{V} \in \mathbb{R}^M$ の実現値
- $\boldsymbol{y}$：確率変数 $\boldsymbol{Y} = \boldsymbol{A}\boldsymbol{X} + \boldsymbol{V} \in \mathbb{R}^M$ の実現値

**信号復元の問題**
→ $\boldsymbol{Y}$ の実現値 $\boldsymbol{Y} = \boldsymbol{y}$ が与えられたときに、$\boldsymbol{X}$ がどのような値をとる可能性が高いかを考える問題

---

## 事後分布と事前分布 (6/15)

✓ 事後分布 = 「$\boldsymbol{Y}$ が与えられたときの $\boldsymbol{X}$ の条件付き分布 $p_{X|Y}(\boldsymbol{x} \mid \boldsymbol{y})$」が大きくなるように復元したい
　❖ 事前分布 = 「条件付きでない分布 $p_X(\boldsymbol{x})$」

事前分布 $p_X(\boldsymbol{x})$ の例
- ガウス分布
- ベルヌーイ・ガウス分布　＝ 各成分が確率 $p_0$ で $0$ となり、確率 $1-p_0$ でガウス分布に従う（$p_0$ が大きければ $\boldsymbol{x}$ がスパースになる）
- 各成分が確率 $0.5$ で $1$ となり、確率 $0.5$ で $-1$ となる

**最大事後確率推定**
$$\hat{\boldsymbol{x}}_{\text{MAP}} = \arg\max_{\boldsymbol{x} \in \mathbb{R}^N} \left\{ p_{X|Y}(\boldsymbol{x} \mid \boldsymbol{y}) \right\}$$

どうモデル化するか？

---

## ベイズの定理に基づく変形 (7/15)

✓ $p_{X|Y}(\boldsymbol{x} \mid \boldsymbol{y})$ は「観測ベクトルが得られたときの未知ベクトルの分布」
→ 観測プロセスと逆の流れで直接的にモデル化しにくい

ベイズの定理
$$p_{X|Y}(\boldsymbol{x} \mid \boldsymbol{y}) = \frac{p_{Y|X}(\boldsymbol{y} \mid \boldsymbol{x}) p_X(\boldsymbol{x})}{p_Y(\boldsymbol{y})}$$
を用いる

$\boldsymbol{x}$ の尤度：観測プロセスを確率的に表現できれば比較的素直にモデル化可能

$$\hat{\boldsymbol{x}}_{\text{MAP}} = \arg\max_{\boldsymbol{x} \in \mathbb{R}^N} \left\{ \frac{p_{Y|X}(\boldsymbol{y} \mid \boldsymbol{x}) p_X(\boldsymbol{x})}{p_Y(\boldsymbol{y})} \right\} = \arg\max_{\boldsymbol{x} \in \mathbb{R}^N} \left\{ p_{Y|X}(\boldsymbol{y} \mid \boldsymbol{x}) p_X(\boldsymbol{x}) \right\}$$

（$p_Y(\boldsymbol{y})$ は $\boldsymbol{x}$ に依存しない）

---

## さらに変形 (8/15)

$$\hat{\boldsymbol{x}}_{\text{MAP}} = \arg\max_{\boldsymbol{x} \in \mathbb{R}^N} \left\{ p_{Y|X}(\boldsymbol{y} \mid \boldsymbol{x}) p_X(\boldsymbol{x}) \right\}$$

log は単調増加関数

$$= \arg\max_{\boldsymbol{x} \in \mathbb{R}^N} \left\{ \log\left( p_{Y|X}(\boldsymbol{y} \mid \boldsymbol{x}) p_X(\boldsymbol{x}) \right) \right\}$$

$$= \arg\max_{\boldsymbol{x} \in \mathbb{R}^N} \left\{ \log p_{Y|X}(\boldsymbol{y} \mid \boldsymbol{x}) + \log p_X(\boldsymbol{x}) \right\}$$

最大化→最小化に

$$= \arg\min_{\boldsymbol{x} \in \mathbb{R}^N} \left\{ -\log p_{Y|X}(\boldsymbol{y} \mid \boldsymbol{x}) - \log p_X(\boldsymbol{x}) \right\}$$

- 尤度：観測プロセスの確率的モデル化
- 事前分布：未知信号の確率的モデル化

## 具体例1：観測雑音がガウス分布する場合 (9/15)

✓ 仮定：雑音 $\boldsymbol{V}$ の分布が平均 $\boldsymbol{0}$・共分散行列 $\sigma_v^2 \boldsymbol{I}$ のガウス分布

$$p_V(\boldsymbol{v}) = \frac{1}{(2\pi\sigma_v^2)^{M/2}} \exp\left( -\frac{1}{2\sigma_v^2} \|\boldsymbol{v}\|_2^2 \right) \text{ に従う}$$

$\boldsymbol{Y}$ の条件付き分布は平均 $\boldsymbol{A}\boldsymbol{x}$・共分散行列 $\sigma_v^2 \boldsymbol{I}$ のガウス分布

$$p_{Y|X}(\boldsymbol{y} \mid \boldsymbol{x}) = \frac{1}{(2\pi\sigma_v^2)^{M/2}} \exp\left( -\frac{1}{2\sigma_v^2} \|\boldsymbol{y} - \boldsymbol{A}\boldsymbol{x}\|_2^2 \right)$$

最大事後確率推定

$$\hat{\boldsymbol{x}}_{\text{MAP}} = \arg\min_{\boldsymbol{x} \in \mathbb{R}^N} \left\{ -\log p_{Y|X}(\boldsymbol{y} \mid \boldsymbol{x}) - \log p_X(\boldsymbol{x}) \right\}$$

$$= \arg\min_{\boldsymbol{x} \in \mathbb{R}^N} \left\{ -\frac{M}{2}\log(2\pi\sigma_v^2) + \frac{1}{2\sigma_v^2}\|\boldsymbol{y} - \boldsymbol{A}\boldsymbol{x}\|_2^2 - \log p_X(\boldsymbol{x}) \right\}$$

$$= \arg\min_{\boldsymbol{x} \in \mathbb{R}^N} \left\{ \frac{1}{2\sigma_v^2}\|\boldsymbol{y} - \boldsymbol{A}\boldsymbol{x}\|_2^2 - \log p_X(\boldsymbol{x}) \right\}$$

## 具体例2：観測雑音がガウス分布＋未知ベクトルもガウス分布 (10/15)

✓ 未知ベクトルの仮定：平均 $\boldsymbol{0}$・共分散行列 $\boldsymbol{I}$ のガウス分布

$$p_X(\boldsymbol{x}) = \frac{1}{(2\pi)^{N/2}} \exp\left( -\frac{1}{2} \|\boldsymbol{x}\|_2^2 \right) \text{ に従う}$$

最大事後確率推定

$$\hat{\boldsymbol{x}}_{\text{MAP}} = \arg\min_{\boldsymbol{x} \in \mathbb{R}^N} \left\{ \frac{1}{2\sigma_v^2}\|\boldsymbol{y} - \boldsymbol{A}\boldsymbol{x}\|_2^2 - \log p_X(\boldsymbol{x}) \right\}$$

$$= \arg\min_{\boldsymbol{x} \in \mathbb{R}^N} \left\{ \frac{1}{2\sigma_v^2}\|\boldsymbol{y} - \boldsymbol{A}\boldsymbol{x}\|_2^2 + \frac{1}{2}\|\boldsymbol{x}\|_2^2 \right\}$$

$\ell_2$ 正則化付き最小二乗法の形

$\ell_2$ 正則化付き最小二乗法は、**未知ベクトルと観測雑音がどちらもガウス分布に従う**と仮定したときの最大事後確率推定

## 具体例3：観測雑音がガウス分布＋未知ベクトルがラプラス分布 (11/15)

✓ 未知ベクトルの仮定：各成分が位置パラメータ0・尺度パラメータ1のラプラス分布に従うとして

$$p_X(\boldsymbol{x}) = \frac{1}{Z} \exp\left( -\|\boldsymbol{x}\|_1 \right) \text{ とする（} Z \text{：正規化定数）}$$

最大事後確率推定

$$\hat{\boldsymbol{x}}_{\text{MAP}} = \arg\min_{\boldsymbol{x} \in \mathbb{R}^N} \left\{ \frac{1}{2\sigma_v^2}\|\boldsymbol{y} - \boldsymbol{A}\boldsymbol{x}\|_2^2 - \log p_X(\boldsymbol{x}) \right\}$$

$$= \arg\min_{\boldsymbol{x} \in \mathbb{R}^N} \left\{ \frac{1}{2\sigma_v^2}\|\boldsymbol{y} - \boldsymbol{A}\boldsymbol{x}\|_2^2 + \|\boldsymbol{x}\|_1 \right\}$$

$\ell_1$ 正則化

$\ell_1$ 正則化付き最小二乗法は、**未知ベクトルがラプラス分布に従い雑音ベクトルがガウス分布に従う**と仮定したときの最大事後確率推定

## 正則化付きの最適化問題と確率的推論の対応 (12/15)

**データ忠実項**　例：$\frac{1}{2}\|\boldsymbol{y} - \boldsymbol{A}\boldsymbol{x}\|_2^2$

**正則化項**　例：$\frac{1}{2}\|\boldsymbol{x}\|_2^2, \ \|\boldsymbol{x}\|_1$

**正則化付きの最適化問題**
$$\underset{\boldsymbol{x} \in \mathbb{R}^N}{\text{minimize}} \quad f(\boldsymbol{x}) + g(\boldsymbol{x})$$

（$\propto$：比例）　$p_{Y|X}(\boldsymbol{y} \mid \boldsymbol{x}) \propto \exp\left( -f(\boldsymbol{x}) \right)$、　$p_X(\boldsymbol{x}) \propto \exp\left( -g(\boldsymbol{x}) \right)$

**確率的推論に基づく最適化問題**
$$\underset{\boldsymbol{x} \in \mathbb{R}^N}{\text{minimize}} \quad -\log p_{Y|X}(\boldsymbol{y} \mid \boldsymbol{x}) - \log p_X(\boldsymbol{x})$$

**尤度**　例：$p_{Y|X}(\boldsymbol{y} \mid \boldsymbol{x}) \propto \exp\left( -\dfrac{1}{2\sigma_v^2}\|\boldsymbol{y} - \boldsymbol{A}\boldsymbol{x}\|_2^2 \right)$

**事前分布**　例：$p_X(\boldsymbol{x}) \propto \exp\left( -\dfrac{1}{2}\|\boldsymbol{x}\|_2^2 \right)$

## 最尤推定 (13/15)

✓ 未知ベクトルについての事前情報が特にない場合
→ 事前分布 $p_X(\boldsymbol{x})$ の値が $\boldsymbol{x}$ に依存しない（定数である）とすると

$$\hat{\boldsymbol{x}}_{\text{MAP}} = \arg\max_{\boldsymbol{x} \in \mathbb{R}^N} \left\{ p_{Y|X}(\boldsymbol{y} \mid \boldsymbol{x}) p_X(\boldsymbol{x}) \right\} = \arg\max_{\boldsymbol{x} \in \mathbb{R}^N} \left\{ p_{Y|X}(\boldsymbol{y} \mid \boldsymbol{x}) \right\}$$

最尤推定（尤度の最大化）

雑音ベクトルがガウス分布に従う場合

$$\hat{\boldsymbol{x}}_{\text{MAP}} = \arg\min_{\boldsymbol{x} \in \mathbb{R}^N} \left\{ \frac{1}{2\sigma_v^2}\|\boldsymbol{y} - \boldsymbol{A}\boldsymbol{x}\|_2^2 \right\}$$

最小二乗法の形

最小二乗法は、**雑音ベクトルがガウス分布に従う**と仮定したときの最尤推定

## 一般のMMSE推定 (14/15)

✓ 非線形な操作も許したときのMMSE推定

**線形のMMSE推定**

$$\underset{\boldsymbol{W} \in \mathbb{R}^{N \times M}}{\text{minimize}} \quad \mathrm{E}\left[ \|\boldsymbol{W}\boldsymbol{y} - \boldsymbol{x}^*\|_2^2 \right]$$

- $\mathrm{E}[\boldsymbol{x}^*] = \boldsymbol{0}, \ \mathrm{E}[\boldsymbol{x}^*(\boldsymbol{x}^*)^\top] = \boldsymbol{R}_x$
- $\mathrm{E}[\boldsymbol{v}] = \boldsymbol{0}, \ \mathrm{E}[\boldsymbol{v}\boldsymbol{v}^\top] = \boldsymbol{R}_v$
- $\boldsymbol{x}^*$ と $\boldsymbol{v}$ は独立

$$\hat{\boldsymbol{x}} = \boldsymbol{R}_x \boldsymbol{A}^\top \left( \boldsymbol{A}\boldsymbol{R}_x \boldsymbol{A}^\top + \boldsymbol{R}_v \right)^{-1} \boldsymbol{y}$$

**一般のMMSE推定**

$$\underset{f}{\text{minimize}} \quad \mathrm{E}_{X|Y}\left[ \|f(\boldsymbol{y}) - \boldsymbol{x}^*\|_2^2 \right] \quad (\boldsymbol{x}^* \sim p_{X|Y}(\boldsymbol{x} \mid \boldsymbol{y}))$$

## 一般のMMSE推定 ＝ 条件付き期待値 (15/15)

条件付き期待値を $\boldsymbol{m} := \mathrm{E}_{X|Y}[\boldsymbol{x}^*] = \displaystyle\int \boldsymbol{x} p(\boldsymbol{x} \mid \boldsymbol{y}) \, d\boldsymbol{x}$ とおくと

$$\mathrm{E}_{X|Y}\left[ \|f(\boldsymbol{y}) - \boldsymbol{x}^*\|_2^2 \right] = \mathrm{E}_{X|Y}\left[ \|f(\boldsymbol{y}) - \boldsymbol{m} + \boldsymbol{m} - \boldsymbol{x}^*\|_2^2 \right]$$

$$= \|f(\boldsymbol{y}) - \boldsymbol{m}\|_2^2 + (f(\boldsymbol{y}) - \boldsymbol{m})^\top \underbrace{\mathrm{E}_{X|Y}[\boldsymbol{m} - \boldsymbol{x}^*]}_{=\ \boldsymbol{0}}$$

$$+ \underbrace{\mathrm{E}_{X|Y}[\boldsymbol{m} - \boldsymbol{x}^*]^\top}_{=\ \boldsymbol{0}} (f(\boldsymbol{y}) - \boldsymbol{m}) + \mathrm{E}_{X|Y}\left[ \|\boldsymbol{m} - \boldsymbol{x}^*\|_2^2 \right]$$

$$= \|f(\boldsymbol{y}) - \boldsymbol{m}\|_2^2 + \mathrm{E}_{X|Y}\left[ \|\boldsymbol{m} - \boldsymbol{x}^*\|_2^2 \right]$$

$$\geq \mathrm{E}_{X|Y}\left[ \|\boldsymbol{m} - \boldsymbol{x}^*\|_2^2 \right] \quad (f(\boldsymbol{y}) = \boldsymbol{m} \text{ のとき等号成立})$$

一般のMMSE推定の結果は条件付き期待値　$f(\boldsymbol{y}) = \mathrm{E}_{X|Y}[\boldsymbol{x}^*]$
