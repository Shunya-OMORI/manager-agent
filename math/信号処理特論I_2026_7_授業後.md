## 線形観測からの信号復元（再掲） (1/18)

未知ベクトル $x^* \in \mathbb{R}^N$ を、その線形観測 $y = Ax^* + v \in \mathbb{R}^M$ から推定

$$M \ \boldsymbol{y} = \boldsymbol{A} \ \boldsymbol{x}^* + \boldsymbol{v}$$

（$N$: 未知ベクトルの次元、$v$: 雑音、推定値 $\hat{x}$）

例：
- 圧縮センシング
- 画像復元
- 無線信号検出

## 最小ノルム解 (2/18)

最小ノルム解では雑音が考慮されない

$$\underset{x \in \mathbb{R}^N}{\text{minimize}} \ \|x\|_2^2 \quad \text{subject to} \ y = Ax$$

$$\Rightarrow \quad x = A^\top (AA^\top)^{-1} y$$

$y = Ax^* + v$ なのに、$y = Ax$ となるように復元してしまう

雑音の存在を考慮して復元するには？

## $\ell_2$ 正則化付き最小二乗法 ｜ 概要 (3/18)

最小二乗法の目的関数に $\|x\|_2^2$ を追加
→ 復元結果の $\ell_2$ ノルムが小さくなるようにする

$$\underset{x \in \mathbb{R}^N}{\text{minimize}} \ \frac{1}{2}\|y - Ax\|_2^2 + \frac{\lambda}{2}\|x\|_2^2$$

$\lambda > 0$：正則化パラメータ
- $\lambda$ が大きい → $\|x\|_2^2$ が小さくなるように復元
- $\lambda$ が小さい → $y = Ax$ をできるだけみたすように復元

## 正則化付き最適化に基づく復元の一般形 (4/18)

観測モデルの情報と復元対象の信号に関する事前知識をどちらも活用

基本的な形：

$$\hat{x} = \arg\min_{x \in \mathbb{R}^N} \left\{ \frac{1}{2}\|y - Ax\|_2^2 + \lambda g(x) \right\}$$

- **データ忠実性**：観測モデル $y = Ax^* + v$ の情報を活用
- **正則化**：$x^*$ に関する事前知識を活用（$\lambda$ は正則化パラメータ）

目的関数 $\frac{1}{2}\|y - Ax\|_2^2 + \lambda g(x)$ は $x$ の関数として最小値をとり、その最小点付近に $x^*$ と推定値 $\hat{x}$ が位置するイメージ。

## 信号に関する事前知識の例 (5/18)

- スパース信号
  - ほとんどの値が0になる
- 画像
  - 隣接する画素の値が近い（空間的に滑らかに変化する）
  - 周波数領域に変換するとスパースになる
  - 行列表現すると低ランクになる
- 動画
  - 時間的に滑らかに変化する
- 無線信号
  - 限られた種類の値のみ（$\pm 1$ のみ、など）をとる

## $\ell_2$ 正則化付き最小二乗法 ｜ 導出 (6/18)

$$\underset{x \in \mathbb{R}^N}{\text{minimize}} \ \frac{1}{2}\|y - Ax\|_2^2 + \frac{\lambda}{2}\|x\|_2^2$$

を解いて $\ell_2$ 正則化付き最小二乗法による復元結果を求めましょう

## $\ell_2$ 正則化付き最小二乗法 ｜ 導出 (7/18)

$$\frac{\partial}{\partial x}\left\{ \frac{1}{2}\|y - Ax\|_2^2 + \frac{\lambda}{2}\|x\|_2^2 \right\} = A^\top(Ax - y) + \lambda x$$

$$\Rightarrow \quad A^\top(Ax - y) + \lambda x = 0$$

$$(A^\top A + \lambda I)x = A^\top y$$

$$x = (A^\top A + \lambda I)^{-1} A^\top y$$

通常の最小二乗法（$A$ が縦長）の場合：$x = (A^\top A)^{-1} A^\top y$

## 行列 $A^\top A + \lambda I$ は正則か？ (8/18)

1. $A^\top A$ は半正定値
　（任意の $x \in \mathbb{R}^N$ に対して $x^\top A^\top A x = \|Ax\|_2^2 \geq 0$ となるため）
2. $\lambda I$ は正定値
　（任意の $x \neq 0$ に対して $x^\top(\lambda I)x = \lambda\|x\|_2^2 > 0$ となるため）
3. 半正定値行列と正定値行列の和は正定値
4. 1～3より、$A^\top A + \lambda I$ は正定値
5. $A^\top A + \lambda I$ の固有値はすべて正
　（→ 行列式（＝全固有値の積）も正）
　なので正則

## 線形のMMSE推定 (9/18)

未知ベクトル：$x^* \in \mathbb{R}^N$
線形観測：$y = Ax^* + v \in \mathbb{R}^M$

**方針**

最小二乗推定や最小ノルム解は雑音の影響を考慮していない
→ そもそも小さくしたいのは $\hat{x} - x^*$ の大きさ（だけど $x^*$ は未知）
→ $x^*$ や $v$ を確率的に取り扱って $\mathrm{E}\left[\|Wy - x^*\|_2^2\right]$ が小さくなる $W$ を求める

$$\underset{W \in \mathbb{R}^{N \times M}}{\text{minimize}} \ \mathrm{E}\left[\|Wy - x^*\|_2^2\right] \quad (\text{推定値: } Wy)$$

MMSE（Minimum Mean Squared Error）推定

## MMSE推定の導出の流れ (10/18)

$$\underset{W \in \mathbb{R}^{N \times M}}{\text{minimize}} \ \mathrm{E}\left[\|Wy - x^*\|_2^2\right]$$

仮定：
- $\mathrm{E}[x^*] = 0, \ \mathrm{E}[x^*(x^*)^\top] = R_x$
- $\mathrm{E}[v] = 0, \ \mathrm{E}[vv^\top] = R_v$
- $x^*$ と $v$ は独立

① 目的関数の変形 →

$$\underset{W \in \mathbb{R}^{N \times M}}{\text{minimize}} \ \mathrm{E}\left[(x^*)^\top A^\top W^\top WAx^*\right] + \mathrm{E}\left[v^\top W^\top Wv\right] - 2\mathrm{E}\left[(x^*)^\top A^\top W^\top x^*\right]$$

② トレースをとって変形 →

$$\underset{W \in \mathbb{R}^{N \times M}}{\text{minimize}} \ \mathrm{tr}\left(WAR_xA^\top W^\top\right) + \mathrm{tr}\left(WR_vW^\top\right) - 2\mathrm{tr}\left(R_xA^\top W^\top\right)$$

③ $W^\top$ での微分＝0 を $W$ について解く

$$W = ?$$

## MMSE推定の導出 ｜ ①目的関数の変形 (11/18)

$$\mathrm{E}\left[\|Wy - x^*\|_2^2\right]$$

$$= \mathrm{E}\left[\|W(Ax^* + v) - x^*\|_2^2\right]$$

$$= \mathrm{E}\left[(Ax^* + v)^\top W^\top W(Ax^* + v)\right] - 2\mathrm{E}\left[(Ax^* + v)^\top W^\top x^*\right] + \mathrm{E}\left[(x^*)^\top x^*\right]$$

$$= \mathrm{E}\left[(x^*)^\top A^\top W^\top WAx^*\right] + 2\mathrm{E}\left[v^\top W^\top WAx^*\right] + \mathrm{E}\left[v^\top W^\top Wv\right]$$
$$\quad - 2\mathrm{E}\left[(x^*)^\top A^\top W^\top x^*\right] - 2\mathrm{E}\left[v^\top W^\top x^*\right] + \mathrm{E}\left[(x^*)^\top x^*\right]$$

$2\mathrm{E}[v^\top W^\top WAx^*]$、$-2\mathrm{E}[v^\top W^\top x^*]$ の項は $x^*, v$ の独立性と $\mathrm{E}[x^*] = 0, \mathrm{E}[v] = 0$ から0。$\mathrm{E}[(x^*)^\top x^*]$ の項は $W$ に依存しない。

$$\underset{W \in \mathbb{R}^{N \times M}}{\text{minimize}} \ \mathrm{E}\left[(x^*)^\top A^\top W^\top WAx^*\right] + \mathrm{E}\left[v^\top W^\top Wv\right] - 2\mathrm{E}\left[(x^*)^\top A^\top W^\top x^*\right]$$

## MMSE推定の導出 ｜ ②トレースをとって変形 (12/18)

$$\underset{W \in \mathbb{R}^{N \times M}}{\text{minimize}} \ \mathrm{E}\left[(x^*)^\top A^\top W^\top WAx^*\right] + \mathrm{E}\left[v^\top W^\top Wv\right] - 2\mathrm{E}\left[(x^*)^\top A^\top W^\top x^*\right]$$

$$\mathrm{E}\left[(x^*)^\top A^\top W^\top WAx^*\right] = \mathrm{E}\left[\mathrm{tr}\left((x^*)^\top A^\top W^\top WAx^*\right)\right]$$
$$= \mathrm{E}\left[\mathrm{tr}\left(WAx^*(x^*)^\top A^\top W^\top\right)\right]$$
$$= \mathrm{tr}\left(WA\,\mathrm{E}\left[x^*(x^*)^\top\right]A^\top W^\top\right)$$
$$= \mathrm{tr}\left(WAR_xA^\top W^\top\right)$$

$$\mathrm{E}\left[v^\top W^\top Wv\right] = \mathrm{E}\left[\mathrm{tr}\left(Wvv^\top W^\top\right)\right] = \mathrm{tr}\left(WR_vW^\top\right)$$

$$\mathrm{E}\left[(x^*)^\top A^\top W^\top x^*\right] = \mathrm{tr}\left(R_xA^\top W^\top\right)$$

$$\underset{W \in \mathbb{R}^{N \times M}}{\text{minimize}} \ \mathrm{tr}\left(WAR_xA^\top W^\top\right) + \mathrm{tr}\left(WR_vW^\top\right) - 2\mathrm{tr}\left(R_xA^\top W^\top\right)$$

## MMSE推定の導出 ｜ ③微分の式を解く (13/18)

$$\underset{W \in \mathbb{R}^{N \times M}}{\text{minimize}} \ \mathrm{tr}\left(WAR_xA^\top W^\top\right) + \mathrm{tr}\left(WR_vW^\top\right) - 2\mathrm{tr}\left(R_xA^\top W^\top\right)$$

$\dfrac{\partial}{\partial W^\top}$（$R_x, R_v$ は対称行列）

$$2AR_xA^\top W^\top + 2R_vW^\top - 2AR_x = O$$

$$(AR_xA^\top + R_v)W^\top = AR_x$$

正則なので

$$W^\top = (AR_xA^\top + R_v)^{-1}AR_x$$

$$W = R_xA^\top(AR_xA^\top + R_v)^{-1}$$

MMSE推定値：$R_xA^\top(AR_xA^\top + R_v)^{-1} y$

$R_x = I, \ R_v = \sigma_v^2 I$ の場合は $A^\top(AA^\top + \sigma_v^2 I)^{-1} y$

## MMSE推定と他の手法の関係 (14/18)

$R_x = I, \ R_v = \sigma_v^2 I$ の場合のMMSE推定値：

$$A^\top(AA^\top + \sigma_v^2 I)^{-1} y$$

$\sigma_v^2 = 0$ の場合 →　最小ノルム解：$A^\top(AA^\top)^{-1} y$

$\lambda = \sigma_v^2$ のとき一致 ←→　$\ell_2$ 正則化付き最小二乗法：$(A^\top A + \lambda I)^{-1} A^\top y$

$(A^\top A + \sigma_v^2 I)A^\top = A^\top(AA^\top + \sigma_v^2 I)$ より
$A^\top(AA^\top + \sigma_v^2 I)^{-1} = (A^\top A + \sigma_v^2 I)^{-1} A^\top$ となるため
（逆行列補題でも導出可能）

## 干渉除去 (16/18)

未知ベクトル $x^*$ の特定の成分 $x_n^*$ のみの復元を考えると他の成分は干渉になる

観測モデル：
$$y = Ax^* + v = \sum_{n=1}^{N} a_n x_n^* + v \qquad (A = [a_1 \ \cdots \ a_N])$$

たとえば $x_1^*$ に着目すると

$$y = \underbrace{a_1 x_1^*}_{\text{所望成分}} + \underbrace{\sum_{n=2}^{N} a_n x_n^*}_{\text{干渉成分}} + \underbrace{v}_{\text{雑音成分}}$$

何かしらの手法で得られた仮の推定値を用いて干渉の影響を除去できれば復元精度が改善されるかも？
→ 無線信号検出などで活用

- 逐次干渉除去
- 並列干渉除去

## 逐次干渉除去 (17/18)

干渉を除去しながら1つずつ成分を推定

1. $y = a_1 x_1^* + \sum_{n=2}^{N} a_n x_n^* + v$ から、観測を $y$、観測行列を $a_1$、雑音を $\sum_{n=2}^{N} a_n x_n^* + v$ と思って $x_1^*$ の推定値 $\hat{x}_1$ を計算（例：ZF推定）

2. $y - a_1\hat{x}_1 \approx a_2 x_2^* + \sum_{n=3}^{N} a_n x_n^* + v$ から、観測を $y - a_1\hat{x}_1$、観測行列を $a_2$、雑音を $\sum_{n=3}^{N} a_n x_n^* + v$ と思って $x_2^*$ の推定値 $\hat{x}_2$ を計算

3. $y - a_1\hat{x}_1 - a_2\hat{x}_2 \approx a_3 x_3^* + \sum_{n=4}^{N} a_n x_n^* + v$ から（以下同様に繰り返す）

- $x_1^*, x_2^*, \ldots, x_N^*$ の大きさに差がある場合に有効
- $x_n^*$ が離散値をとる場合は推定値を丸めてからの干渉除去も可能
