## 反復アルゴリズムの収束 (1/16)

- 反復アルゴリズム:同じ形の計算を繰り返し行うアルゴリズム
  - → $k$ 反復目の結果 $x^{(k+1)} \in \mathbb{R}^N$ が一つ前の $x^{(k)}$ のみで表現できる場合、ある写像 $T: \mathbb{R}^N \to \mathbb{R}^N$ を用いて $x^{(k+1)} = T(x^{(k)})$ となる

例:勾配降下法 $T(x) = x - \alpha \nabla f(x) \quad (\alpha > 0)$

$$\lim_{k \to \infty} \|x^{(k)} - \bar{x}\|_2^2 = 0 \text{ となるとき、}$$

点列 $x^{(k)}$ $(k = 0, 1, \dots)$ は $\bar{x}$ に**(強)収束する**といい、 $\displaystyle \lim_{k \to \infty} x^{(k)} = \bar{x}$ と書く

（点列 $x^{(0)}, x^{(1)}, x^{(2)}, x^{(3)}, \dots$ が $\bar{x}$ に近づいていく様子）

## 写像の不動点 (2/16)

- 収束先の $\bar{x}$ では、写像 $T$ による更新をしても変化がないはず

実際、$T$ が連続であれば $\displaystyle\lim_{k \to \infty} T(x^{(k)}) = T\left(\lim_{k \to \infty} x^{(k)}\right)$ なので

$$T(\bar{x}) = T\left(\lim_{k \to \infty} x^{(k)}\right) = \lim_{k \to \infty} T(x^{(k)}) = \lim_{k \to \infty} x^{(k+1)} = \bar{x}$$

$x_{\text{fix}} = T(x_{\text{fix}})$ をみたす $x_{\text{fix}} \in \mathbb{R}^N$ を写像 $T$ の**不動点**とよぶ

例:勾配降下法 $T(x) = x - \alpha \nabla f(x)$ の不動点は

$$x_{\text{fix}} = x_{\text{fix}} - \alpha \nabla f(x_{\text{fix}})$$
$$\nabla f(x_{\text{fix}}) = \mathbf{0}$$

より $f$ の停留点

## 反復アルゴリズムは不動点に近づくか? (3/16)

**反復アルゴリズム設計の戦略(の1つ)**
求めたい値(例:最適解)を不動点にもつ写像 $T$ を構成し、$T$ に基づく反復計算によって不動点を求める

写像 $T$ による反復 $x^{(k+1)} = T(x^{(k)})$ は必ず $T$ の不動点に収束するか?
→ **No**

例:
勾配方向への上昇 $T_+(x) = x + \alpha \nabla f(x)$ は $f$ の停留点を不動点にもつが、$f$ が大きくなる方向に移動するため $f$ が凸関数であれば収束しない

## 収束する例としない例(一変数関数) (4/16)

初期値 $x^{(0)}$ $(> 1)$ からスタートしたときの様子(不動点: $x = 0, 1$)

**$T(x) = \sqrt{x}$** の場合:収束する
（初期値 $x^{(0)}$ から $x^{(1)}, x^{(2)}, \dots$ と反復するにつれ、点列は不動点 $x=1$ に近づいていく）

**$T(x) = x^2$** の場合:収束しない
（初期値 $x^{(0)}$ から $x^{(1)}, x^{(2)}, \dots$ と反復するにつれ、点列は不動点 $x=1$ から離れていく）

## 反復アルゴリズムが不動点に収束するには? (5/16)

- 反復アルゴリズム $x^{(k+1)} = T(x^{(k)})$ が不動点 $x_{\text{fix}}$ に収束するには?
  - → インデックス $k$ が大きくなるにつれて、$x^{(k)}$ と $x_{\text{fix}}$ の差が小さくなっていけば良さそう

例: $\|x^{(k+1)} - x_{\text{fix}}\|_2 \le \kappa \|x^{(k)} - x_{\text{fix}}\|_2$ となる $\kappa \in (0,1)$ が存在

$\|x^{(k+1)} - x_{\text{fix}}\|_2 \le \kappa \|x^{(k)} - x_{\text{fix}}\|_2$ のとき

$$\|x^{(k)} - x_{\text{fix}}\|_2 \le \kappa \|x^{(k-1)} - x_{\text{fix}}\|_2$$
$$\le \kappa^2 \|x^{(k-2)} - x_{\text{fix}}\|_2$$
$$\vdots$$
$$\le \kappa^k \|x^{(0)} - x_{\text{fix}}\|_2$$
$$\to 0 \ (\text{as } k \to \infty)$$

## 縮小写像 (6/16)

$\|x^{(k+1)} - x_{\text{fix}}\|_2 \le \kappa \|x^{(k)} - x_{\text{fix}}\|_2$ を写像 $T$ に関する条件にする

$$\|x^{(k+1)} - x_{\text{fix}}\|_2 \le \kappa \|x^{(k)} - x_{\text{fix}}\|_2$$

$x^{(k+1)} = T(x^{(k)}), \ x_{\text{fix}} = T(x_{\text{fix}})$ より

$$\|T(x^{(k)}) - T(x_{\text{fix}})\|_2 \le \kappa \|x^{(k)} - x_{\text{fix}}\|_2$$

$x^{(k)}$ や $x_{\text{fix}}$ に依存しない形に

**縮小写像**
ある $\kappa \in (0,1)$ が存在して、任意の $x_1, x_2 \in \mathbb{R}^N$ に対して $\|T(x_1) - T(x_2)\|_2 \le \kappa \|x_1 - x_2\|_2$ となる写像

※ リプシッツ定数が1未満のリプシッツ連続な写像

## バナッハの不動点定理 (7/16)

**バナッハの不動点定理**
写像 $T: \mathbb{R}^N \to \mathbb{R}^N$ が縮小写像であるとき、
- $T$ の不動点 $x_{\text{fix}}$ はただ一つ存在する
- 任意の $x^{(0)}$ に対して、$x^{(k+1)} = T(x^{(k)})$ によって定義される点列 $x^{(k)}$ は $T$ の不動点 $x_{\text{fix}}$ に収束する

## 非拡大写像 (8/16)

- 縮小写像の条件は強すぎて使いにくい
  - → もう少し緩めた条件を考える

**縮小写像**
ある $\kappa \in (0,1)$ が存在して、任意の $x_1, x_2 \in \mathbb{R}^N$ に対して $\|T(x_1) - T(x_2)\|_2 \le \kappa \|x_1 - x_2\|_2$ となる写像

**非拡大写像**
任意の $x_1, x_2 \in \mathbb{R}^N$ に対して $\|T(x_1) - T(x_2)\|_2 \le \|x_1 - x_2\|_2$ となる写像

※ 1-リプシッツ連続な写像

## 非拡大写像の不動点 (9/16)

- 非拡大写像であれば不動点が必ず存在するか?
  - → **No**

例:
$T(x) = x + 1$ は

$$|T(x_1) - T(x_2)| = |(x_1 + 1) - (x_2 + 1)| = |x_1 - x_2|$$

となるので非拡大写像だが明らかに不動点は存在しない

## 非拡大写像の不動点への収束 (10/16)

- 非拡大写像 $T$ が不動点をもっていれば $x^{(k+1)} = T(x^{(k)})$ で不動点に収束するか?
  - → **No**

例:
$T(x) = -x$ は

$$|T(x_1) - T(x_2)| = |(-x_1) - (-x_2)| = |x_1 - x_2|$$

となるので非拡大写像であり $x = 0$ を不動点にもつが…

$x^{(0)} = 1, x^{(1)} = -1, x^{(2)} = 1, \dots$ となり収束しない

## 非拡大写像による更新のイメージ (11/16)

非拡大写像 $T$ が不動点をもつときに、不動点に収束する点列を得たい

中心 $x_{\text{fix}}$・半径 $\|x - x_{\text{fix}}\|_2$ の球を考える。

$T(x)$ は球の内部か境界上にある
→ 境界上にある場合、不動点 $x_{\text{fix}}$ との距離は縮まらない

ただし、線分上の点 $(1-\alpha)x + \alpha T(x)$ $(\alpha \in (0,1))$ は球の内部にある

## $\alpha$-平均非拡大写像 (12/16)

**$\alpha$-平均非拡大写像**
ある非拡大写像 $T$ を用いて
$$\tilde{T} = (1-\alpha)\mathrm{Id} + \alpha T$$
と書ける写像 $\tilde{T}$ (Id:恒等写像)

$$\tilde{T}(x) = (1-\alpha)x + \alpha T(x)$$

**性質**

- $T$ と $\tilde{T}$ の不動点(の集合)は一致する
- $\tilde{T}$ による反復
$$x^{(k+1)} = (1-\alpha)x^{(k)} + \alpha T(x^{(k)})$$
は $\tilde{T}$ の不動点($=T$ の不動点)に収束する

$$\tilde{T}(x_{\text{fix}}) = x_{\text{fix}}$$
$$\Leftrightarrow (1-\alpha)x_{\text{fix}} + \alpha T(x_{\text{fix}}) = x_{\text{fix}}$$
$$\Leftrightarrow T(x_{\text{fix}}) = x_{\text{fix}}$$

## Mann iteration (13/16)

$\alpha$-平均非拡大写像による反復

$$x^{(k+1)} = (1-\alpha)x^{(k)} + \alpha T(x^{(k)})$$

→ 反復ごとに $\alpha$ を変える

**(Krasnosel'skiĭ-)Mann iteration**

$$x^{(k+1)} = (1-\alpha_k)x^{(k)} + \alpha_k T(x^{(k)})$$

**定理** 非拡大写像 $T: \mathbb{R}^N \to \mathbb{R}^N$ は不動点をもつとする。$\alpha_k$ が $\sum_{k=0}^{\infty} \alpha_k(1-\alpha_k) = \infty$ をみたすとき、任意の $x_0 \in \mathbb{R}^N$ に対して

$$x^{(k+1)} = (1-\alpha_k)x^{(k)} + \alpha_k T(x^{(k)})$$

によって得られる点列は $T$ の不動点の1つに収束する。

## 堅非拡大写像 (14/16)

$\dfrac{1}{2}$-平均非拡大写像のことを堅非拡大写像と呼ぶ
→ (非拡大写像による反復は収束するとは限らないが)

堅非拡大写像による反復は収束する

**堅非拡大写像 (firmly nonexpansive operator)**
ある非拡大写像 $T$ を用いて
$$\tilde{T} = \frac{1}{2}\mathrm{Id} + \frac{1}{2}T$$
と書ける写像 $\tilde{T}$ (Id:恒等写像)

**性質**

① $\tilde{T}$ が堅非拡大 $\Leftrightarrow$ $\mathrm{Id} - \tilde{T}$ が堅非拡大
② $\tilde{T}$ が堅非拡大 $\Leftrightarrow$ $2\tilde{T} - \mathrm{Id}$ が非拡大 $\Leftrightarrow$ $\mathrm{Id} - 2\tilde{T}$ が非拡大

## 勾配降下法の収束 (1/2) (15/16)

- 写像が堅非拡大であることを示せれば反復アルゴリズムの収束性を示せる

例: 勾配降下法であれば、

$$x^{(k+1)} = x^{(k)} - \alpha \nabla f(x^{(k)})$$
$$= \underbrace{(\mathrm{Id} - \alpha \nabla f)}_{= \tilde{T}}(x^{(k)})$$

と書けるので写像 $\tilde{T} = \mathrm{Id} - \alpha \nabla f$ が堅非拡大ならOK
($f$ が微分可能な凸関数で、停留点が存在することを仮定)

性質①より、写像 $\alpha \nabla f$ が堅非拡大ならOK

$\alpha \nabla f$ が堅非拡大になるための条件は?

## 勾配降下法の収束 (2/2) (16/16)

Baillon-Haddadの定理:
微分可能な凸関数 $f$ に対して、$\nabla f$ が堅非拡大であることと $\nabla f$ が非拡大であることは同値

写像 $\alpha \nabla f$ が非拡大なら勾配降下法は収束

$$\|\alpha \nabla f(x_1) - \alpha \nabla f(x_2)\|_2 \le \|x_1 - x_2\|_2$$
$$\|\nabla f(x_1) - \nabla f(x_2)\|_2 \le \frac{1}{\alpha}\|x_1 - x_2\|_2$$

勾配 $\nabla f$ が $\beta$-リプシッツ連続 ($\beta \le 1/\alpha$) であれば

$$\|\nabla f(x_1) - \nabla f(x_2)\|_2 \le \beta \|x_1 - x_2\|_2 \le \frac{1}{\alpha}\|x_1 - x_2\|_2$$

→ ステップサイズ $\alpha$ を $0 \le \alpha \le 1/\beta$ となるように選べば収束
