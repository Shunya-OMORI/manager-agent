# NEDO 提案書作成

## Goal

NEDO Challenge の提案テーマについて、提案書様式に沿って各項目を埋められる状態にする。

## Deadline

数日中から数か月中。提出期限や中間確認日が分かり次第、ここに追記する。

## Expected Outputs

- 提案書各項目の箇条書き案
- 解決すべき課題と未解決点の整理
- 市場規模、科学的妥当性、社会実装に関する根拠資料
- ユーザ確認後の確定版ドラフト

## Required Inputs

- `tasks/20260604.md`
- `nedo/ミーティング決定事項.txt`
- `nedo/提案書様式.txt`
- `nedo/初期案.txt`
- `research/idea.md`

## Working Directories

- Context: `nedo/context/`
- Evidence URLs: `nedo/research/urls.md`
- Papers/PDFs: `nedo/research/papers/`
- Source summaries: `nedo/research/summaries/`
- Drafts before approval: `nedo/drafts/`
- Confirmed outputs: `nedo/outputs/`
- Logs: `nedo/logs/`
- Current state: `nedo/status.md`

## Rules

- いきなり本文確定に入らず、先行事例・論文・市場根拠を調査する。
- 設計方針は原則 3 案提示してから進める。
- 文章編集はユーザ許可後、小段落単位で行う。
- 既存ファイルは、明示許可なしに移動・リネームしない。
