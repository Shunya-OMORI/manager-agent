・学部3年後期
　## 1. 発明の概要と目的
　　・本案は、脳波（EEG）、音声、画像といったマルチモーダルデータから、ユーザが言語化できない潜在的な支援要求（ニーズ）を段階的に推定し、自己改善する情報処理装置、方法およびプログラムに関するものである。
　　・従来の感情推定や言語復号技術の限界を克服し、実生活の文脈に適した具体的な「支援要求文」を生成することで、エージェントによる先回り支援や社会的サービスの向上を実現することを目的とする。

　## 2. 従来技術の限界と本発明の立ち位置
　　従来技術には以下の技術的課題が存在していた。
　　・* **感情推定（Affective Computing）：** 感情ラベル（不安など）の推定に留まり、具体的な行動志向（「休みたい」のか「確認したい」のか）まで同定できない。
　　・* **言語復号（Brain-to-Text）：** 主に発話運動の代替を目的としており、潜在的ニーズの生成や日常的な自己改善ループが設計されていない。
　　・* **クエリ意図分類（IR）：** 文字列中心の解析であるため、同一クエリであってもユーザの内的状態（焦り、疲労など）を区別できない。

　### 技術比較
　・本技術は、生体信号と周辺文脈を組み合わせ、「方向性（連続） $\rightarrow$ カテゴリ（離散） $\rightarrow$ 文（生成）」の3段階で潜在的ニーズを構造化し、生活支援（介入・学習）へ接続する点で一線を画す。

　## 3. 核心的技術要素（3段階推定と自己改善ループ）
　・本システムは以下の4つのコンポーネントにより構成される。

```
[生体信号 + 周辺文脈]
         │
         ▼
① 支援要求の方向性推定 (query_vector)
         │
         ▼
② 支援要求のカテゴリ推定 (Reason / Action)
         │
         ▼
③ 支援要求文そのものの推定 (定型文生成)
         │
         ▼
④ 自己改善ループ (ユーザ反応のLLM要約 ──> 再学習)

```
　　### ① 支援要求の方向性推定（query_vector_generator）
　　・脳波（z-score化および特徴量アンカーの重み付き和）、音声（文字起こし）、画像（マルチモーダルLLMによる説明テキスト）から、現在の支援要求の埋め込みベクトル（`query_vector`）を推定する。モデル構造には**Perceiver**を採用。損失関数に対比学習やヒンジ損失を導入することで、未知データに対しても高い意味類似度（Cosine Similarity: 0.9117）での予測を達成している。
　　### ② ニーズカテゴリ推定（need_classifier）
　　・支援要求を「Reason（理由：12クラス）」**と**「Action（行動：31クラス）」の2軸に分解し、確率分布を出力する。
　　・`query_vector`と各クラスのプロトタイプ（中心ベクトル）との幾何学的差分特徴（差分、要素積など）をCNN/MLPでトークン化し、Transformerで相互作用を学習する。理由と行動の損失関数をまとめて評価（クロスエントロピーの和の最小化）することで、高い分類精度（Reason Top-1: 0.722、Action Top-1: 0.789）を実現している。
　　### ③ 支援要求文そのものの推定（need_text_generator）
　　・自由に作文させるのではなく、前段で得たカテゴリと方向性に基づき、以下の定型フォーマットに整形する。
　　　> 「ユーザーは `<Reason>` ので `<Action>` したいと思っている」
　　・モデルは `meta-llama-Llama-3.2-1B-Instruct` をベースとし、`query_vector` を特殊トークン `<QUERY>` の埋め込みとして注入する **QueryPrefix法** と **LoRA** による微調整を組み合わせる。テストデータに対する意味類似度は0.9257を記録し、高い生成安定性を確保している。
　　### ④ 自己改善ループ
　　・支援エージェントの提案（介入）に対するユーザの反応（採用、拒否など）のログを、外部LLM（Gemini-2.5-flashなど）を用いて要約・教師文としてデータセットへ統合し、各モデルをオンラインまたはバッチで再学習する。これにより、実生活の運用を通じて精度が継続的にカスタマイズされる。

　## 4. 介入制御と技術的効果
　　・* **生体信号トリガ駆動：** 介入（エージェントによるサポート提案）の制御は、推定の不確実性だけでなく、脳波のパワーパワースペクトル密度（PSD）やコヒーレンスなどの**生体信号指標の急激な変化・持続**を主たるトリガとする。
　　・* **言語入力への非依存：** ユーザが発話やキーボード入力を行っていない状況でも、状態変化に同期した先回り支援（チェックリスト提示、質問生成など）が可能となる。
　　・* **責務の明確化：** 「支援要求文の推定」と「具体的な提案生成（エージェント）」を分離したことで、将来的な提案生成器の差し替えや拡張が容易である。

　## 5. 主な実施例（ユースケース）
　　・1. **作業中の確認ニーズ（不安解消）：**
　　　PC作業中に脳波のβ/γ帯域パワーが上昇し、音声から不安の動詞句が検知された場合、Reason「不安なので」、Action「確認したい」を推定。システムが自動でチェックリストや手順提案を提示する。
　　・2. **散漫状態における気分転換ニーズ：**
　　　脳波の$\alpha/\beta$比等の変化から退屈・散漫状態を検知。Reason「暇なので」、Action「雑談で紛らわせたい」等を推定し、エージェントが適切な休憩やタスク切り替えの提案を行う。

　## 6. 進歩性の主張ポイント
　　1. 生体信号の用途を「感情分類」に留めず、実効的な「支援要求（行動志向）」にまで接続した点。
　　2. 意味空間における方向性ベクトル（`query_vector`）を中核に据え、パイプラインの一貫性と類似検索性を担保した点。
　　3. クラス定義の変更に強い「query−prototype 差分学習」によるカテゴリ推定を採用した点。
　　4. QueryPrefixと教師文の定型化により、小型LLMでも高い生成精度と制御性を両立した点。
　　5. 言語入力がない場面でも介入を可能にする、生体信号指標の変化点・持続駆動型のトリガ機構を備えている点。

　　・知りたいこと，想像したもの，タスクなど，頭の中に思い浮かべる事象の多くは人間が能動的に処理する必要がある．
　　→ すぐには具現化できない，または実現できないケースが多い
　　・ユーザーの理想を自らアクションを起こすエージェントを用いて具現化・実現・記録するシステム

　■ 全体的な目標：ユーザーの理想を具現化するエージェントの構築
　① エージェントがユーザー周囲の観測結果を分析
　② 最適な推測結果やサポートを提案（出力）
　③ 提案に対して理想に近い選択肢を（脳波などを用いて）選択する
　④ 選択された結果を分析し，より理想に近い選択肢を再度提案
　フィードバック（③～④）を高速で繰り返し，真の理想に近づける

　■プロトタイプの構築
　・分析対象を「ユーザーが聴いている音楽」に限定
　・音楽を聴いて思い浮かべた情景を画像として生成
　・楽曲を聴いている際の EEG のパワー比と PLV を算出
　・RAG で論文を渡し，確かな脳波の知識を得た Gemini に楽曲の特徴（キー，テンポ，歌詞等）を渡し，楽曲を聴いている際にユーザがイメージした可能性のある情景を3つテキストで出力
　・それぞれの情景のテキストを画像生成モデル DALL-E 3 に入力し，画像を生成
　・脳波を入れなかった場合の方が脳波を入れた場合と比べて生成された情景にばらつきが生じるという結果を得た．
　・LLM による分析・情景の生成部分に関して
　　・EEG 指標が小さな小数になったので，そのまま Gemini に与えると，実際にはその値が自分の印象に合っていても，「パラメータの影響が小さい」と判断されてしまうケースがある
　　　→ パラメータや快/不快を段階や百分率で渡す などの対策
　　・曲名に引っ張られすぎた回答
　　　・モンスターハンターの楽曲であればモンスターと戦士が描かれるようなケース（ユーザーが必ずしも曲名と一致した情景をイメージしているわけではない）
　　　→ 入力情報と脳波情報の重みの調整を，フィードバックで実現
　■ 生成器としての性能
　　・実際にはかなりイメージに近い画像を生成できているが，感情→情景の精度を向上させるには，ユーザーの日常や幼少期の風景もソースとして必要
　■ エージェントの中枢部分に関して
　　・フィードバックと機械学習の早期実装が不可欠
　　　→ ユーザーと会話を行い，生成器や重みを制御する部分の実装
　　・会話や周囲の観察から，ユーザーが認識または記憶したオブジェクトや映像，会話等を DB に保存
　　　→ 感情と情景の結びつきをはじめ，よりユーザーに寄り添うことが可能

・学部1年前期
　1. 研究の目的
　　・身体運動制御研究の多くは線形な制御対象を仮定しているが、実際の身体は非線形な運動方程式に従う 。
　　・従来の最適制御理論（iLQGなど）は未知の環境変化や身体の変化（運動適応）が生じた際に状態予測の正確性を欠くという課題がある 。
　　・本研究では、誤差に晒された場合でも柔軟に対応でき、非線形な制御対象を扱える枠組みとして、非線形な運動方程式を高次元空間へ拡張して線形化するKoopman operator（クープマン作用素）に着目した 。
　　・ヒトの膨大な脳内ニューロンがこの作用素に類似した計算を行っているという仮説のもと、その生物学的妥当性を検証することを目的とする 。  
　2. 実験方法および実装
　　・対象モデル: 複雑な非線形制御の標準参照モデルである「2関節ロボットアームの標準モデル」の運動方程式を対象とした 。  
　　・線形化の手法: ニューラルネットワーク（AutoencoderおよびKoopman operatorを組み合わせたモデル）を用いて、運動方程式の線形化を学習させた 。
　　・損失関数の勾配を算出して重みを更新し、予測性能を最小化するよう最適化した 。  
　　・神経活動の再現: 高次元空間への線形化を担うニューラルネットワークの第4層の活動（$Dat\_act(ite).A4$）を検出し、その平均（$MeanAct$）を算出 。
　　・これを、先行研究（Georgopoulos et al., 1982）におけるサルの運動皮質単一細胞の放電頻度データ（運動方向依存的なcosine tuning）と比較した 。  
　3. 実験結果
　　・予測性能の確保: 学習のイテレーションを重ねることで、AutoencoderおよびKoopman operatorのテストエラーは十分に低下し、実験に必要な予測性能に達した 。  
　　・運動方向による活動変化: 試行ごとに異なる関節角度や位置を入力した結果、運動方向に応じて各ニューロンの活動量や時間分布が変化することが確認された 。  
　　・生体データとの相関: 抽出した神経素子の中には、活動が最大になる運動方向（好みの方向）を持つものが存在した 。
　　・実際のサルのニューロンの活動データとの相関係数を求めたところ、15番目の素子で -0.68、30番目で 0.81、80番目で 0.37 となり、生体データに対して非常に近い挙動を示す素子（30番目）と、遠い挙動を示す素子に分かれる結果となった 。  
　4. 結論
　　・本研究により、Koopman operatorを用いて非線形システムを高次元線形空間へ拡張する人工神経素子の活動と、実際の脳内ニューロンの活動の双方において、「活動が最大になる運動方向が存在する」という共通の特徴が見出された 。
　　・これは生物の脳内において、Koopman operatorに類似した計算が行われている可能性を説明する、神経活動の再現性を示した一成果であると言える 。
