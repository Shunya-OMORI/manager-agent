# dog-human-comm — イヌとヒトのコミュニケーション革新

2026年度（学部4年）の卒業研究テーマの検討場所である。
教授の指示は「ミリ波，加速度，光などのセンサでイヌの心拍を測り，
ヒトとイヌのコミュニケーション革新を実現する」ことであった。

## 中心となる主張

**要求とは，恒常性を回復させる介入である。**

イヌの感情ラベルを当てるのをやめ，要求を「その個体の自律神経状態を
セットポイントへ引き戻す介入」として操作的に定義する。飼い主の日常的な介入
（給餌，撫でる，ドアを開ける，声をかける，あえて何もしない）を教師信号の
供給源とみなし，介入後の自律神経の回復そのものを報酬として潜在要求ベクトルを
学習する。アノテーションを必要としない。
