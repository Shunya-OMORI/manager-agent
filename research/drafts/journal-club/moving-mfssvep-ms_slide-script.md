### Slide 2. 概要

**表示**

1. **背景**：MSでは，視覚入力と眼球運動の両方に障害が生じる．
2. **課題**：両機能の定量検査には，専門設備と別々の検査が必要である．
3. **提案**：移動するmfSSVEP刺激により，EEGとEOGを同時に計測する．
4. **結果**：MS群ではmfSSVEP SNRが低かったが，眼球追従性能には群間差がなかった．

**図のテキスト表現**

```text
点滅  → EEG → 求心性指標：mfSSVEP SNR
同じ刺激
移動  → EOG → 遠心性指標：眼球追従性能
```

**セリフ**

1. MSでは，眼から脳へ入る視覚入力と，脳から眼球運動系へ出る運動指令の両方が障害されます．
2. しかし，この二つを定量的に測るには，専門設備を使って別々に検査する必要があります．
3. 著者らは，点滅しながら移動する刺激を提示し，EEGとEOGから両機能を同時に評価しました．
4. その結果，視覚入力を表すmfSSVEP SNRには群間差がありましたが，眼球追従性能には群間差がありませんでした．

**設計意図**

- 求心性と遠心性を初出時に日常語へ置き換える．
- 背景，課題，提案，結果を一文ずつ対応させ，論文全体の地図を作る．
- 最後に成功と不成功を並べ，結果を過大評価しない．

### Slide 3. 多発性硬化症と視覚系

**表示**

1. 多発性硬化症（MS）は，中枢神経系の脱髄性疾患である．
2. 視覚系は，症状が明瞭でない段階でも障害を捉えられる可能性がある．
3. 視覚系には，情報が入る経路と指令が出る経路がある．

**図のテキスト表現**

```text
求心性：眼 ──視覚情報──▶ 脳
         「見えた情報が脳へ入る」

遠心性：脳 ──運動指令──▶ 眼球運動系
         「脳の指令で眼が動く」
```

**セリフ**

1. MSは，中枢神経系の髄鞘が損傷する疾患で，視神経や眼球運動に関わる神経経路も障害されます．
2. 視覚系は，診察で症状が明瞭でない段階でも脱髄性障害を捉えられる可能性があります．
3. ここで重要なのが，視覚情報が眼から脳へ入る求心性経路と，運動指令が脳から眼球運動系へ出る遠心性経路の区別です．
4. 本発表では，求心性を視覚入力，遠心性を眼球運動の指令として捉えると，全体を理解しやすくなります．

**設計意図**

- 専門語を矢印の向きと対応させ，記憶の足場を作る．
- 「求心性＝感覚」「遠心性＝運動」だけで済ませず，本論文での具体的対象を示す．

### Slide 4. MSにおける視覚機能検査

**表示**

| 評価対象 | 代表的な検査 | 主にわかること |
| --- | --- | --- |
| 求心性 | 低コントラスト視力 | 見え方の低下 |
| 求心性 | VEP | 視覚入力に対する脳応答 |
| 求心性 | OCT | 網膜・視神経の構造 |
| 遠心性 | 眼球運動計測 | サッカード・smooth pursuit |

**スライド下部**

**既存検査は有用だが，機器と専門性が分散している．**

**セリフ**

1. 求心性機能は，低コントラスト視力，VEP，OCTなどで評価できます．
2. このうちVEPは，視覚刺激に対する脳の電気応答を測るため，本研究のEEG指標に近い検査です．
3. 遠心性機能は，サッカードやsmooth pursuitなどの眼球運動から評価します．
4. それぞれの検査は有用ですが，必要な機器と専門知識が分散しているため，同じ場所で一度に測ることは容易ではありません．

**設計意図**

- 検査名を列挙するだけでなく，評価対象との対応を表で固定する．
- 最後の一文で次の「既存検査の課題」へ接続する．

### Slide 5. 既存検査の課題

**表示**

1. **場所の制約**：大型装置と専用設備を備えた施設が必要である．
2. **人の制約**：神経眼科と信号解析の専門知識が必要である．
3. **検査の分断**：求心性機能と遠心性機能を別々に測定する．

**結論**

**患者のいる場所で，両機能を同時に測れる検査が必要である．**

**図のテキスト表現**

```text
従来：
患者 →［VEP室］→［OCT］→［眼球運動計測室］

目標：
患者 →［一つの可搬型システム］
```

**セリフ**

1. 既存検査の第一の課題は，大型装置や専用設備を備えた施設が必要なことです．
2. 第二の課題は，検査と解析に神経眼科や信号処理の専門知識が必要なことです．
3. 第三の課題は，視覚入力と眼球運動を別々の検査として測ることです．
4. そこで著者らは，検査室へ患者を移動させるのではなく，患者のいる場所へ持ち運べる一体型システムを目指しました．

**設計意図**

- 制約を「場所，人，検査」の同じ粒度で整理する．
- 結論を単独で置き，提案手法が必要になる理由を明示する．

### Slide 6. 提案手法：移動型mfSSVEP

**表示**

1. HMD内に，20区画からなる多焦点点滅刺激を提示する．
2. 刺激全体を二次元空間内で滑らかに移動させる．
3. EEGとEOGから，二種類の応答を同じ試行で取得する．

**図のテキスト表現**

```text
                 移動型mfSSVEP刺激
        ┌────────────────────┐
        │ 20区画が異なる周波数で点滅 │
        │ 刺激全体が画面内を移動     │
        └────────────────────┘
               ↓ 同時に誘発
       EEG：mfSSVEP    EOG：smooth pursuit
```

**セリフ**

1. 提案手法は，HMD内に20区画の多焦点点滅刺激を提示します．
2. この刺激全体を移動させ，参加者には中心の赤点を眼で追わせます．
3. 点滅はEEG上のmfSSVEPを誘発し，移動はEOGで測定できるsmooth pursuitを誘発します．
4. したがって，一つの刺激と一つの課題から，求心性と遠心性の指標を同時に取得できます．

**設計意図**

- 装置の細部より先に「点滅」と「移動」の二機能を示す．
- 3文目と4文目で刺激，信号，機能指標の対応を確定する．

---

### Slide 7. 点滅から求心性機能を測る

**表示**

1. 各区画は，8.0--11.8 Hzの異なる周波数で点滅する．
2. 視覚野は，刺激周波数に同期したEEG応答を示す．
3. mfSSVEP SNRは，視覚入力が脳へ届いた強さを表す．

**図のテキスト表現**

```text
8.0 Hzで点滅 ─┐
8.2 Hzで点滅 ─┼─▶ 眼 ─▶ 視覚経路 ─▶ 後頭部EEG
      …       │                         │
11.8 Hzで点滅 ┘                 同じ周波数にピーク

強いピーク：刺激に同期した応答が強い
弱いピーク：刺激に同期した応答が弱い
```

**セリフ**

1. 求心性機能は，眼から脳へ入る視覚情報の伝わり方です．
2. 各区画を異なる周波数で点滅させると，視覚野のEEGには同じ周波数の応答が現れます．
3. 本研究は，刺激周波数に現れた応答の強さをmfSSVEP SNRとして定量化しました．
4. SNRが低い場合は，刺激へ同期した視覚応答が相対的に弱いと解釈します．

**設計意図**

- 求心性を再定義した直後に，刺激から指標までを一本道で説明する．
- SNRを一般的な信号品質ではなく，本論文の定義に沿って説明する．

---

### Slide 8. 移動から遠心性機能を測る

**表示**

1. 参加者は，移動する刺激中心を眼で追う．
2. 脳からの運動指令により，smooth pursuitが生じる．
3. 刺激位置と水平EOGの相関を，眼球追従性能とする．

**図のテキスト表現**

```text
刺激位置：  ／＼＿＿／＼＿＿／
水平EOG：   ／＼＿＿／＼＿＿／   → 相関が高い

刺激位置：  ／＼＿＿／＼＿＿／
水平EOG：  ＿／￣＼＿／￣＼＿   → 相関が低い
```

**セリフ**

1. 遠心性機能は，脳から眼球運動系へ出る運動指令の働きです．
2. 参加者が移動刺激を追うと，刺激の動きに合わせたsmooth pursuitが生じます．
3. 本研究は，刺激の水平位置と水平EOGがどの程度同じ変化を示すかを相関係数で評価しました．
4. 相関が高いほど，眼球が刺激の左右方向の動きへ忠実に追従したと解釈します．

**設計意図**

- Slide 7と同じ文型を使い，求心性と遠心性を対称に理解できるようにする．
- 「相関が高い＝軌跡が完全に一致」とは言い切らず，左右方向の変化への追従と限定する．

### Slide 9. 一つの刺激から二つの指標を得る

**表示**

```text
［入力］移動しながら点滅する刺激
          │
          ├─ 点滅周波数 ─▶ 後頭部EEG ─▶ mfSSVEP SNR
          │                              求心性
          │
          └─ 水平位置   ─▶ 水平EOG   ─▶ 位置との相関
                                         遠心性
```

**スライド下部**

**周波数タグと移動軌跡を同じ刺激へ重ねたことが，本手法の新規性である．**

**セリフ**

1. ここまでの対応を一つの流れにまとめます．
2. 点滅周波数はEEG応答を生み，そのSNRが求心性指標になります．
3. 刺激の移動は眼球運動を生み，水平位置との相関が遠心性指標になります．
4. 本手法の新規性は，周波数タグと移動軌跡を同じ刺激へ重ね，二つの経路を同時に調べた点です．

**設計意図**

- Slides 6--8の情報を統合し，方法の核を一枚で再確認する．
- 「HMDを使ったこと」ではなく「二種類の情報を刺激へ重ねたこと」を新規性として示す．

### Slide 10. 実験条件

**表示**

| 項目 | MS群 | 健常群 |
| --- | ---: | ---: |
| 参加者 | 9名 | 10名 |
| 平均年齢 | 32.7 ± 4.33歳 | 24.9 ± 7.2歳 |
| 女性 | 66.6% | 80% |

1. 刺激：5秒提示＋1秒休憩
2. 条件：2眼×2パターン×3セッション×30試行
3. 総試行数：1名当たり360試行

**図のテキスト表現**

```text
1試行：［刺激 5秒］［休憩 1秒］

片眼・片パターン：
30試行 × 3セッション ＝ 90試行
```

**セリフ**

1. 実験には，MS患者9名と健常者10名が参加しました．
2. MS群の平均年齢は32.7歳，健常群は24.9歳であり，群間に約7.8歳の差があります．
3. 一試行は5秒の刺激提示と1秒の休憩からなります．
4. 各参加者は，両眼，二つの刺激パターン，三セッション，三十試行の組合せで，合計360試行を実施しました．

**設計意図**

- 参加者数と年齢差を結果解釈に必要な情報として先に示す．
- 総試行数を積の形で示し，後の計測時間と90試行平均を理解しやすくする．

### Slide 11. 解析方法

**表示**

```text
EEG：2,048 Hzで記録
  ↓ 256 Hzへリサンプリング・フィルタ
  ↓ 5秒エポックを90試行平均
  ↓ DFT
  ↓ mfSSVEP SNR

EOG：2,048 Hzで記録
  ↓ 256 Hzへリサンプリング
  ↓ 水平EOGを算出
  ↓ 刺激水平位置との相関

群比較：年齢を共変量とした一元配置ANCOVA
```

**セリフ**

1. EEGとEOGは2,048 Hzで記録し，解析時に256 Hzへリサンプリングしました．
2. EEGでは，各眼・各刺激パターンの5秒エポック90試行を平均した後，DFTによって振幅スペクトルを求めました．
3. 求心性指標には刺激周波数成分と非刺激周波数成分の比であるSNRを用いました．
4. 遠心性指標には水平EOGと刺激の水平位置との相関を用いました．
5. 最後に，年齢差を調整するため，年齢を共変量とした一元配置ANCOVAで群を比較しました．

**設計意図**

- 二つの解析を上下に並べ，同時計測後は別の指標へ分岐することを示す．
- フィルタの細部や式はAppendixへ送り，本編では判断に必要な処理だけを残す．

### Slide 12. 結果

**表示**

| 指標 | 健常群 | MS群 | 群間差 |
| --- | ---: | ---: | --- |
| mfSSVEP SNR | 2.54 ± 0.76 | 2.19 ± 0.47 | `p = 0.049` |
| 眼球追従性能 | 68.71 ± 14.16 | 68.33 ± 11.75 | `p = 0.753` |

**結論**

1. 求心性指標：MS群で低下した．
2. 遠心性指標：群間差を確認できなかった．

**セリフ**

1. 結果は，二つの指標で異なりました．
2. mfSSVEP SNRは，健常群の2.54に対してMS群は2.19で，年齢調整後の群間差は`p = 0.049`でした．
3. 一方，眼球追従性能は両群とも約68で，群間差は`p = 0.753`でした．
4. したがって，求心性機能の低下を示す仮説は支持されましたが，遠心性機能の低下を示す仮説は支持されませんでした．

**設計意図**

- 数値，統計，解釈を同じ行へ対応させる．
- 「遠心性機能に差がない」ではなく「この実験では差を確認できなかった」と解釈する．

### Slide 13. 求心性指標：mfSSVEP SNR

**表示**

```text
mfSSVEP SNR

健常群  2.54 ± 0.76  █████████████
MS群    2.19 ± 0.47  ███████████

F(1,34) = 4.18, p = 0.049
```

1. MS群では，刺激周波数へ同期したEEG応答が相対的に弱かった．
2. この結果は，求心性視覚機能の低下と整合する．

**セリフ**

1. 求心性指標では，MS群のmfSSVEP SNRが健常群より低い結果でした．
2. これは，MS群では点滅刺激の周波数へ同期したEEG応答が相対的に弱かったことを示します．
3. この結果は，視覚情報が眼から脳へ伝わる過程の機能低下と整合します．
4. ただし，`p = 0.049`は有意水準をわずかに下回る値であり，強い確証ではなく予備的な結果として扱う必要があります．

**設計意図**

- 棒の高さ，生理学的意味，統計的な慎重さを順に説明する．
- SNR低下から脱髄部位や診断能力までを推論しない．

### Slide 15. 個別例では差が見える

**表示**

**Fig. 3の内容を簡略化**

```text
［上：mfSSVEP振幅スペクトル］
周波数        8.0                    11.8 Hz
健常眼        ↑  ↑ ↑  ↑ ↑  ↑  ↑  ↑ ↑  ↑
MS眼          ·  ↑ ·  · ↑  ·  ·  ↑ ·  ·
              刺激周波数帯

［下：刺激軌跡と眼球軌跡］
健常眼：刺激 ─────────
        EOG  ─────────  ほぼ重なる

MS眼：  刺激 ─────────
        EOG  ──／──＼──  一部で外れる
```

**スライド下部**

**代表例の差は，群全体の差を意味しない．**

**セリフ**

1. Fig. 3では，健常者とMS患者の代表例が示されています．

## Appendix

### Appendix 1. SSVEPとmfSSVEP

**表示**

1. SSVEPは，周期的な点滅に同期して生じるEEG応答である．
2. mfSSVEPは，視野を複数区画へ分け，各区画へ異なる周波数を割り当てる．
3. 周波数タグにより，複数の視野領域の応答を同時に識別できる．

**図のテキスト表現**

```text
SSVEP：
1個の刺激［10 Hz］→ EEG［10 Hzにピーク］

mfSSVEP：
区画A［8.0 Hz］ ┐
区画B［8.2 Hz］ ├→ EEG［各周波数にピーク］
区画C［8.4 Hz］ ┘
```

**セリフ**

1. SSVEPは，周期的な視覚刺激へ同期してEEGに現れる定常的な応答です．
2. mfSSVEPでは，視野を複数区画へ分け，区画ごとに異なる点滅周波数を割り当てます．
3. 各周波数が区画の識別子として働くため，複数領域の応答を同時に評価できます．

---

### Appendix 2. 20区画と刺激周波数

**表示**

```text
3個の同心円上に合計20区画

視野角：8.4°，21°，35°
周波数：8.0--11.8 Hz，0.2 Hz間隔
```

**セリフ**

1. 刺激は三つの同心円上に配置した20区画からなります．
2. 各区画には，8.0 Hzから11.8 Hzまで，0.2 Hz間隔の異なる周波数を割り当てました．
3. この配置により，中心から周辺までの複数視野領域へ同時に周波数タグを付けています．

### Appendix 3. 5秒エポックの意味

**表示**

```text
周波数分解能 Δf = 1 / T

T = 5 s
Δf = 1 / 5 = 0.2 Hz

刺激周波数の間隔 ＝ DFTの周波数分解能
```

**セリフ**

1. 5秒エポックを用いる理由は，DFTの周波数分解能と刺激周波数の間隔を一致させるためです．
2. 観測時間が5秒なら，周波数分解能は0.2 Hzになります．
3. したがって，0.2 Hz間隔で配置した刺激周波数を別々の周波数ビンとして評価できます．

### Appendix 4. SNRとパターンA/B

**表示**

```text
Pattern A target：
8.0, 8.4, 8.8, ..., 11.6 Hz

Pattern B target：
8.2, 8.6, 9.0, ..., 11.8 Hz

SNR =
刺激した周波数の振幅総和
────────────────
刺激しなかった周波数の振幅総和
```

**セリフ**

1. パターンAとBは，点滅させる周波数を交互に分けた刺激です．
2. あるパターンで点滅した周波数はtargetとなり，もう一方で点滅しなかった近接周波数はnon-targetとなります．
3. 本研究のSNRは，target周波数の振幅総和をnon-target周波数の振幅総和で割った値です．
4. この比較により，刺激へ選択的に同期した成分を近接周波数の背景成分に対して評価します．

### Appendix 5. 水平EOGと相関係数

**表示**

```text
hEOG = 右眼外側電極 − 左眼外側電極

眼球追従性能
＝ corr（hEOG，刺激の水平位置）
```

1. `r`が高いほど，左右方向の変化が刺激と一致する．
2. `r`は，追従の振幅誤差や時間遅延を完全には表さない．

**セリフ**

1. 水平EOGは，左右の眼の外側に置いた電極の差から求めます．
2. 本研究は，水平EOGと刺激の水平位置のPearson相関を眼球追従性能としました．
3. 相関は変化の形が一致するかを表しますが，追従振幅の倍率差や時間遅延を十分に評価できない場合があります．

### Appendix 10. 左右眼の非独立性

**表示**
