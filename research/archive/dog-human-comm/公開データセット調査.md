# 公開データセット調査

卒業研究の制約は「実験は最小限，基本は公開データセットで学習」である。
この制約が満たせるかを，実在するデータセットに当たって判定した。

## 結論を先に

**イヌについて，「介入」と「生理応答」を対にした公開データセットは存在しない。**
一方で，**ヒトについては存在する（`WESAD`）**。したがって，

- ヒトを主戦場にして公開データだけで原理を立証し，
- イヌでは最小限の自前計測（数頭・数十エピソード）で原理の移植を示す

という順序になる。これは妥協ではなく，むしろ提案の論理と一致する。
ヒトは「言語報告で答え合わせができる唯一の種」であり，
イヌは「言語報告が原理的に得られない極限ケース」だからである。

さらに **本命のイヌのデータは，実は既に取られているが公開されていない**
（後述の Somppi ら，Koskela ら）。著者への提供依頼は，メール1本のコストで
自前実験を丸ごと省ける可能性がある。**最優先の次アクションはこれである。**

## A. イヌのデータセット

### A-1. PhysioZoo イヌ ECG データベース ★使う

| 項目 | 内容 |
|---|---|
| 入手先 | PhysioNet（オープンアクセス），[physiozoo.com](https://www.physiozoo.com/) |
| 規模 | イヌ **17頭**，1頭1レコード |
| 信号 | 体表電極による ECG，**500 Hz**，平均 5分31秒（4:09〜6:48） |
| 条件 | **覚醒・安静**，無投薬 |
| アノテーション | 手修正済み R 波位置，信号品質ラベル（不良区間 約2.7%） |
| 参考値 | `RMSSD` 中央値 53.9 ms（IQR 41.2–89.8），`SDNN` 69.2 ms，`LF/HF` 0.49 |

**充足度の判定: 目的の学習には不足。ただし必須。**

介入も行動ラベルもない。安静時5分間のECGだけである。
本提案の学習には直接使えない。

しかし次の三つに不可欠である。

1. **R 波検出・HRV 算出パイプラインの検証**。手修正済み R 波が正解として付いている。
   自作の前処理が正しいことを，公開データで示せる。
2. **イヌの `HF` 帯域を再定義する根拠**。実データで呼吸帯域を確認できる。
3. **セットポイント $\theta_i$ の妥当性の参照値**。安静時 `RMSSD` の分布が分かる。

### A-2. DogMove（イヌ行動 IMU データセット） ★使う

| 項目 | 内容 |
|---|---|
| 入手先 | [Mendeley Data](https://data.mendeley.com/datasets/vxhx934tbn/1)（Kaggle にもミラーあり） |
| 規模 | **45頭**（中〜大型犬） |
| 信号 | ActiGraph GT9X Link，3軸加速度＋3軸ジャイロ，**100 Hz**，首輪とハーネスの**2点** |
| ラベル | ギャロップ，伏臥，座位，嗅ぐ，立位，速歩，歩行 など |

**充足度の判定: 心拍がないので単体では不足。だが二つの役割で効く。**

1. **姿勢・活動量の推定器**をここで学習・検証できる。
   [論点1](論点1_回復の定義.md) の交絡除去（体動の共変量）と，
   セットポイント推定に必要な**睡眠・安静区間の自動抽出**が，このデータで作れる。
2. 首輪とハーネスの2点同時計測なので，**体動アーチファクトの構造**を調べられる。

### A-3. Somppi・Katayama ら（29頭，5情動場面） ▲非公開・要請すべき

| 項目 | 内容 |
|---|---|
| 論文 | [Dog–Owner Relationship, Owner Interpretations and Dog Personality...](https://pmc.ncbi.nlm.nih.gov/articles/PMC9179432/) |
| 規模 | **29頭**（ボーダーコリー15，ラブラドール14） |
| 場面 | 撫でる／Kong トイ／**分離**／**再会**／新奇物体（各5分，固定順） |
| 指標 | `RMSSD` |
| 公開状況 | **非公開**（"Study data are available upon request."） |

**判定: これがまさに欲しい構造のデータである。** 「介入（分離・再会・撫でる）→ 生理応答」
という本提案の学習単位そのものである。公開されていないのが惜しい。

### A-4. Koskela ら（25組，飼い主との相互作用） ▲非公開・要請すべき

| 項目 | 内容 |
|---|---|
| 論文 | [Behavioral and emotional co-modulation during dog–owner interaction](https://pmc.ncbi.nlm.nih.gov/articles/PMC11502769/) |
| 規模 | **25組**の飼い主とイヌ |
| 構成 | 事前ベースライン10分 → 撫でる／訓練／嗅がせる／遊ぶ（各6分）→ 事後ベースライン10分 |
| 信号 | Bittium Faros 180 による **ECG 1000 Hz ＋ 3軸加速度 100 Hz**，飼い主とイヌの**両方** |
| 公開状況 | **非公開**（メタデータのみ DOI 10.17011/jyx/dataset/96,732） |

**判定: A-3 よりさらに理想的である。**
事前・事後ベースラインがあり（＝セットポイントが取れる），ECG と加速度が同期しており
（＝体動の交絡が除去でき），**飼い主とイヌを同時計測している**（＝双方向性・
co-regulation が扱える）。本提案が必要とする要素をすべて備えている。

### A-5. その他

- Invoxia スマート首輪の大規模心拍・呼吸データ（[biorxiv](https://www.biorxiv.org/content/10.1101/2023.06.09.544347.full.pdf)）— **非公開**。
- 「Quantified Canine」（[arXiv:2301.06964](https://arxiv.org/pdf/2301.06964)）— ウェアラブルからの性格推定。データ公開は確認できず。

## B. ヒトのデータセット — ここが主戦場になる

### B-1. WESAD ★★ 本命

| 項目 | 内容 |
|---|---|
| 入手先 | [UCI Machine Learning Repository](https://archive.ics.uci.edu/ml/datasets/WESAD+(Wearable+Stress+and+Affect+Detection))（公開） |
| 規模 | **15名** |
| 信号 | 胸部 RespiBAN（ECG，EMG，EDA，**呼吸**，体温，3軸加速度）＋ 手首 Empatica E4（BVP，EDA，体温，加速度） |
| プロトコル | ベースライン20分 → 娯楽（面白い動画）→ **ストレス（TSST）** → **瞑想 約7分 ×2** → 回復 |
| ラベル | 状態ラベルに加え，本人の主観申告（`STAI`，`SAM` 等） |

**充足度の判定: 本提案のヒト側検証にそのまま使える。ほぼ理想的である。**

理由を明示する。

1. **瞑想セッションが「介入」そのものである。** ストレス負荷（`TSST`）で状態が乱れ，
   そこへ瞑想という介入が入り，回復が起きる。
   本提案の学習単位（状態 → 介入 → 回復）が最初から入っている。
2. **呼吸が実測されている。** [論点1](論点1_回復の定義.md) で決めた
   「呼吸実測に基づく `RSA`」を，ヒトで先に検証できる。
3. **加速度がある。** 体動の交絡除去を検証できる。
4. **本人の主観申告がある。** これが決定的である。生理的回復から推定した潜在要求ベクトルが，
   **本人が言葉で報告した状態と一致するか**を確かめられる。イヌでは絶対にできない答え合わせが，
   ヒトではできる。

**限界:** 介入の種類が少ない（瞑想のみ，しかも実験者が与えたもので，
自然発生した介入ではない）。行動集合が小さいので，
「どの介入を選ぶべきか」という選択問題としては弱い。

### B-2. SWELL-KW

知識労働中のストレス。心拍・HRV に加えて，PC 操作ログ，表情がある。
時間圧・メール割り込みといったストレッサはあるが，**明示的な「介入」がない**。
`WESAD` の補助として汎化性の確認に使える程度である。

### B-3. NICU 乳児心拍データセット（乳児 2,780 名，時系列 36,679 本）

10分レコード（2秒サンプリング）。`HRV` 水準と徐脈イベントのラベル付き。
**言語化できないヒト**というテーマの直系である。ただし**介入がアノテーションされていない**ため，
本提案の学習には直接使えない。将来の展開先として位置づける。

なお，介入と自律神経応答の関係は，この領域で臨床的に確立している
（[Family Nurture Intervention で心拍が有意に低下](https://pubmed.ncbi.nlm.nih.gov/34517207/)，
[スキンシップで `SDNN` が 10.44→6.70 ms へ変化](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC10544889/)）。
**本提案の前提（介入は自律神経に測定可能な変化を起こす）は，ヒトで既に立証済み**である。
この事実は，提案のイントロで強く使える。

## C. ミリ波レーダのデータセット

| データセット | 規模・内容 | 入手先 |
|---|---|---|
| 60 GHz FMCW 多対象バイタル | 2名同時，ECG 参照付き | Mendeley Data |
| 包括的 mmWave FMCW バイタル | 10名。心拍上昇時，喘息者，**瞑想実践者**を含む。Polar H10 で参照 | [arXiv:2405.12659](https://arxiv.org/abs/2405.12659) |
| 年齢均衡・多被験者 60 GHz | **110名**。市販 60 GHz レーダ 2台。医療機器クラス IIa の ECG・加速度を参照 | Zenodo（Scientific Data 2026） |
| 120 GHz ミリ波バイタル | 同期参照記録付き | Scientific Data 2026 |
| **マカクザルのミリ波バイタル** | 非接触で**ヒト以外の動物**を計測した先行例 | [Sci Rep 2024](https://www.nature.com/articles/s41598-024-63994-w) |

**充足度の判定: ミリ波から心拍・呼吸を取り出す信号処理部は，公開データだけで完全に開発・検証できる。**

ただしすべて**ヒト**（1件はマカク）であり，**イヌのミリ波公開データは存在しない**。
被毛と四足姿勢と激しい体動は，ヒトのデータからは学べない。ここだけは自前計測が要る。

マカクの先行研究があることは追い風である。「非接触ミリ波は他種にも適用できる」という
前例が査読者に示せる。

## D. 卒業研究としての現実的な計画

| 段階 | 使うもの | 実験 | 何を示すか |
|---|---|---|---|
| **1** | `WESAD` | なし | 「介入後の恒常性回復」を報酬とする潜在要求ベクトルの学習が成立することを，**主観申告との一致**で立証する。提案の心臓部。 |
| **2** | PhysioZoo，DogMove | なし | イヌの HRV パイプライン（R波検出，犬用の帯域再定義，睡眠区間抽出，体動補正）を公開データで検証する。 |
| **3** | 公開ミリ波データ | なし | ミリ波からの心拍・呼吸抽出を検証する。 |
| **4** | **自前計測（最小限）** | **数頭 × 数十エピソード** | 段階1で立証した原理がイヌへ移植できることを示す。介入は給餌・撫でる・退室と再会・無介入の4種程度に絞る。 |
| **0'** | **Somppi / Koskela への提供依頼** | なし | 当たれば段階4が不要か，大幅に軽くなる。**コストはメール1本。今すぐやるべき。** |

段階1〜3は実験ゼロで進む。卒業研究の主要な貢献を，公開データだけで作れる。
自前実験は段階4のみであり，しかも「原理の移植可能性を示す」という限定的な役割に留まる。

## E. ユーザに確認したい判断

1. **Somppi ら（29頭）と Koskela ら（25組）へデータ提供を依頼するか。**
   田中先生から先方へ一報を入れてもらえると成功率が上がる。文面はこちらで用意できる。
2. 段階4の自前計測を，どの犬で行うか（研究室・知人・大学の動物実験倫理審査の要否）。
3. ヒト（`WESAD`）を主，イヌを従とする構成を，教授の指示（イヌの心拍を測れ）と
   どう折り合わせるか。**イヌのミリ波計測は段階4で必ず行う**ので指示は満たすが，
   研究の重心はヒト側に置く，という説明で通るかどうか。
